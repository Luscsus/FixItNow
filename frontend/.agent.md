# React + Vite + Tailwind + shadcn/ui + TanStack Query

- Favor functional components with hooks; no class components.
- Keep layers separated: DTOs in src/dto, mappers in src/mappers, domain in src/domain, services in src/services, hooks in src/hooks, UI in src/components.
- Naming: components PascalCase in PascalCase files, hooks camelCase as useX in camelCase files, services camelCase in camelCase files.
- Prefer TypeScript type aliases for DTOs and domain models, interfaces for component props.
- Avoid inline styles; prefer Tailwind utility classes and small reusable UI components.
- React Query: co-locate query hooks in src/hooks, keep query keys stable and descriptive.
- Use relative imports only inside a layer; use @/ alias for cross-layer imports.
