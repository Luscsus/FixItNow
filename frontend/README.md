# Frontend Starter

React + TypeScript + Vite with Tailwind, shadcn/ui, TanStack Query, and PWA support.

## Scripts

- npm run dev
- npm run build
- npm run preview

## Layered Architecture

- DTO: src/dto
- Mapper: src/mappers
- Domain: src/domain
- Service: src/services
- Hook: src/hooks
- Component: src/components

## Environment

- VITE_API_BASE_URL (default: http://localhost:8080)
